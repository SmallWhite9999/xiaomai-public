# 公開範圍與使用說明

本 repo 公開小麥的研究目錄、成果與限制、適合公開的實驗證據，以及小型示範。完整核心原始碼維持私有；本次發布沒有新增公開 True runtime、研究決策核心、模型前向／反向、完整 optimizer 或私人保存點。

## 這次新增什麼

- 38 個歷史實驗目錄家族的導覽及核對層級。
- 已查核的歷史模型實驗正負結果，包含沒有形成可用方法的紀錄。
- 10/13 R20 單一 MLP 區塊的限定 CUDA 結果公開節錄。
- 10/14 多層 synthetic CPU 盲測的逐案例公開資料與原有失敗。
- 只讀取公開證據、核對算術與判定的標準函式庫示範。

完整程式目錄存在、某個測試曾通過、模型曾執行與方法有效，是不同的主張。每份公開資料說明對應來源、匯出範圍與未完成項。

## 保留私有的內容

完整研究與模型核心、權重、實際 checkpoint／optimizer state、原始私人對話、存取憑證、主機控制設定及未適合公開的資料，不包含在這次增補。

部分歷史來源 hash 用於固定公開節錄依據；公開節錄不能取代私人原件，也不足以獨立重現完整 9B 實驗。已公開的值與算術可以由公開示範核對，數值模型本身沒有在本次發布中重跑。

## 使用與授權

沿用來源仍依各自授權與 NOTICE。這次沒有替所有專案檔案新增全域授權，也沒有把上游授權延伸成全部研究成果的授權。原有來源與授權入口見 [LICENSES](../LICENSES/README.md)。

公開內容可以被讀取及複製；GitHub 對公開倉庫提供查看與 fork 功能。作者標示與版本紀錄用於追溯來源，不能從技術上阻止他人取得副本。授權使用範圍與具體程式的第三方條件須分別判讀。參考 [GitHub 授權說明](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)。
