# 小麥研究週報 / Xiaomai research updates

每週一篇 Markdown，網站的「研究週報」頁面（`/updates/`、`/en/updates/` 與 RSS）由這裡自動產生，不另外改網站。

One Markdown file per week. The website's research update pages and RSS feeds are generated from this folder.

## 新增一期 / Adding an issue

1. 複製 `TEMPLATE.md`，檔名用 ISO 週次，例如 `2026-W42.md`（10/12–10/18）。
2. `issue` 是期數，依週次 1、2、3… 連續編號，不能跳號。
3. 填 frontmatter（見下方欄位）。
4. 本文依序四段，小標題固定、順序不能改：
   - `## 中文`：這週做成了什麼／沒做成的／接下來
   - `## English`：What we got done／What didn't work／What's next
   - `## 技術紀錄`：本週完成／驗證與數字／失敗與未完成／作者與 AI 分工／下一步
   - `## Technical record`：同上英文
5. 在網站專案執行 `node scripts/build-updates.mjs --source-dir <這個資料夾> --out-dir dist-pages`，再照常部署。
6. 募資開跑後，同一篇也貼到嘖嘖的「專案更新」，讓贊助者收到通知。

## 欄位 / Fields

| 欄位 | 說明 |
|---|---|
| `title` | 一句話說這週最重要的事，失敗也可以當標題。中文 60 字內。 |
| `shortTitle` | 選填雙語短標，供首頁膠囊；中文最多 40 字、英文最多 100 字，缺省使用完整標題。有失敗時保留失敗結果，不能只留下成功。 |
| `tldr` | 開頭摘要，2–4 句：做成什麼、為什麼重要、什麼沒成功。 |
| `author` | 署名，用第一人稱寫本文。 |
| `figure` | 本期的一張結果圖：`compare` 型，兩邊數字並排對照（例如重開 A／B）。只放有來源的結果；依摘要重畫時必須在 caption 標明，不能稱為原始測試截圖。沒有就填 `null`。 |
| `notice` | 需要特別說明的狀態，例如研究暫停。沒有就填 `null`。 |
| `version` | 選填。一行寫本期對應的研究線與正式研究保存點，只使用有來源的編號。名稱不代表全部原始模型權重或執行狀態相同；傳承有缺口時放進技術紀錄。升版時另附正式入口、冷恢復核對範圍及發版說明。沒有就填 `null`。 |
| `roadmap` | 首頁四個研究步驟這週各自的狀態：`done` 已做到、`partial` 部分做到、`active` 進行中、`failed` 嘗試未成、`todo` 尚未驗證，各附一句說明。 |
| `timeline` | 每日紀錄，放在技術紀錄裡：`pass` 通過、`partial` 部分通過、`fail` 未通過、`event` 一般紀錄（文件、備份等）。 |
| `sources` | 1–8 個固定 commit 的 HTTPS 連結；第一個也是圖的資料來源。 |
| `stage` | 募資成功、正式開發起算前一律用 `prelaunch`。 |

## 寫法 / Style

- 白話段落寫給一般支持者，約 400–800 字：一件主要的事寫清楚，其他用短清單。不用內部代號，數字要能在技術紀錄對到。
- 失敗照寫，而且寫清楚失敗在哪裡。沒有新實驗的週也照常發，寫整理了什麼、沒做什麼；文件更新不當成研究成果。
- 技術紀錄寫給研究者：完整數字、範圍限制、公開來源。
- 可用段落、`-` 清單、粗體、行內 code、HTTPS 連結，以及用 ``` 圍起來的示例區塊（開頭那行 ``` 後面可加一句說明；含 ✕ 的行顯示為紅色、含 ✓ 的行為綠色）。不放表格、圖片或 HTML。
- 不寫本機路徑、私人權重、hash 或憑證；示意內容要標明是示意。

- 候選階段的 `published` 欄位暫記整理日期，頁面顯示「紀錄整理日期」。正式發布前核定實際公開日；建置候選頁並不表示已發布。Atom feed 使用 `<updated>` 表示本期整理時間，不自動宣稱發布時間。
- `evidenceThrough` 是研究實跑證據的截止日，不能自動填成週末或公開日期。範本沿用上一個已核對停點；有新證據才更新。每一步的狀態必須依本期證據填寫，不能沿用範本當作已驗收。
- `sources_YYYY-Www.json` 保留逐期來源與界線；它是支援資料，不會直接作為網頁或 feed 對外複製。
- 同次建置從這些檔案產生首頁索引；首頁膠囊與最新卡片共用本期文字。少於三期顯示最新一期，累積三期後顯示最近三期；整理下一期時不用另外改首頁文案。
