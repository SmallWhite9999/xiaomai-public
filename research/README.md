# 小麥研究總覽

[回到專案首頁](../README.md) · [目前進度](../docs/current_status.md)

小麥關心的是：模型如何形成和修正研究問題，從觀測中找到方法，再檢查改變能否保存、重用。這裡先介紹研究方向，再提供結果與工程紀錄的閱讀入口。

## 六個研究方向

| 方向 | 想回答的問題 |
|---|---|
| 形成問題與學習 | 模型能否從經驗與矛盾發現問題，修正自己的研究方向？ |
| 探索未知規則 | 面對不熟悉的世界，能否用查詢、推導與驗證找出規則？ |
| 形成可重用的知識 | 讀過材料、做過實驗後，能否留下可執行、可轉用的方法？ |
| 比較推理方式 | 如何在清楚的條件下，比較不同架構與推理路徑？ |
| 理解與修改模型 | 如何追查模型內部的運算，檢查修改真正造成的影響？ |
| 驗證與選擇改進 | 如何用固定評估與證據，決定哪些候選值得保留？ |

這些是研究問題，成果以各份報告的實際範圍為準。公開內容包含成果、證據摘要與小型示範；核心原始碼維持私有。
