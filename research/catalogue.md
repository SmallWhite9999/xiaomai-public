# 小麥研究目錄：38 個歷史實驗家族

整理日期：2026-10-15。此版公開研究題目、成果摘要與證據界線，核心原始碼維持私有。

這份目錄來自 200 個分支當前 head 的樹狀目錄盤點，共六群、38 個家族。**38 是來源目錄家族數，不是 38 項已成立成果，也不表示每個目錄能直接執行。** 下表的中文題目方便導覽，不額外主張該研究已成功。

本次查讀三份歷史結果報告，另 35 個家族尚未在本次逐項核對結果。三份報告內的逐筆原始回覆與動作，本次也未重算；本次新增模型實驗數為 0。

狀態分成兩層：每項的「來源」表示已在歷史分支的 Git tree 中找到該家族；「結果」表示本次是否讀到固定版本結果報告。來源存在與工程測試通過都不能代替能力驗證。

## 與既有公開研究頁的關係

[問題形成與經驗累積](experiments.md) 已有較早研究摘要，本次未重查其每項原始來源，因此上表仍標為「本次尚未核對原始結果」。既有摘要的存在，與這次新增的三份結果報告查讀分開記錄。

這份目錄保留尚未核對的家族，讓讀者看見研究範圍與缺口。未核對項目目前不附成效數字，後續須取得固定來源、核對分母與正負結果後才補入。歷史版本號與目錄數量不代表模型代次或能力等級。
